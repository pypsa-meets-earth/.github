## Hi there 👋,
Welcome to the PyPSA meets Earth initiative, an independent global research and development initiative which aims to provide cutting-edge energy modeling tool for any country in the world.

🌈 We are maintaining the following projects
- [PyPSA-Earth](https://github.com/pypsa-meets-earth/pypsa-earth) provides a way to build a high-resolution a power or sector-coupled models of any country, region or continent focusing at the transmission level
- [PyPSA-Distribution](https://github.com/pypsa-meets-earth/pypsa-distribution) is a tool for optimizing power or sector-coupled distribution systems with high spatial and temporal resolution
- [PyPSA-Earth-Documentation](https://github.com/pypsa-meets-earth/documentation) contains a collection of tutorial materials to get started with modeling and analyze the results
- [Earth-OSM](https://github.com/pypsa-meets-earth/earth-osm) is a package for extracting power infrastructure data from OpenStreetMap for any region of interest in a flexible and customizable way
- [PyPSA-Earth-Status](https://github.com/pypsa-meets-earth/pypsa-earth-status) intends to track the quality of PyPSA-Earth-based energy models by country, and coordinating the global validation efforts

❤️ PyPSA-Earth relies on [PyPSA ecosystem](https://github.com/pypsa) which provides tools to prepare data on renewable energy potentials, installed capacities, technologies costs as well as facilitate interfacing a model with a solver.

⭐ Referenced initiatives:
- [Awesome Electrical Grid Mapping](https://github.com/open-energy-transition/Awesome-Electrical-Grid-Mapping) is a collection of reference sources of power grids worldwide including reference datasets on the transmission capacity
- [MapYourGrid](https://mapyourgrid.org/) is the global mapping initiative which empowers individuals, communities and nations around the world to map the electrical grid. It can help you to improve quality of the power grid data in your region of interest
- [Awesome Electricity Demand](https://github.com/open-energy-transition/Awesome-Electricity-Demand) contains a curated collection of links to hourly or sub-hourly electricity demand data worldwide
- Advanced [Land AVailability Analysis](https://github.com/DEA-GE/LAVA) is atlite-compartible tool to calculate the available area in a user defined study region for building renewable power generators like utility-scale ground-mounted solar PV and wind onshore
- [Energy-climate cookbook](https://github.com/matteodefelice/energy-climate-cookbook) provides an overview of educational resources relevant for energy modelers and gives a hand-on introduction into a using climate data in energy modeling
